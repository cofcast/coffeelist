# DRIP.LOG

> 오늘의 커피를 기억하는 가장 단순한 방법.

DRIP.LOG는 마셨던 커피의 이름과 향미, 추출 방식, 평점을 간결하게 기록하는 개인 커피 저널입니다. 복잡한 기능을 덜어내고 한 잔의 인상을 오래 기억하는 데 집중했습니다.

**배포된 서비스:** [DRIP.LOG 바로가기](https://drip-log-coffee-journal.cofcast23.chatgpt.site)

## 주요 기능

- 커피 이름, 로스터리, 원산지, 날짜 기록
- 핸드드립, 에스프레소, 아메리카노, 라떼, 콜드브루 추출 방식 선택
- 5점 만점 평점과 테이스팅 노트 작성
- 향미 태그를 이용한 커피 특징 정리
- 원두, 로스터리, 원산지, 향미 통합 검색
- 추출 방식별 기록 필터링
- 전체 커피 수, 평균 평점, 가장 자주 마신 방식 자동 집계
- 기록 삭제 및 빈 검색 결과 안내
- 데스크톱, 태블릿, 모바일 반응형 레이아웃

## 디자인

- Pretendard 서체
- 블랙앤화이트 중심의 모던하고 단순한 구성
- 텍스트와 선을 활용한 저널 스타일
- 그라데이션 및 불필요한 장식 이미지 미사용
- 키보드 포커스와 모션 감소 설정을 고려한 인터랙션

## 데이터 저장

작성한 기록은 브라우저의 `localStorage`에 자동 저장됩니다. 새로고침하거나 같은 브라우저로 다시 방문해도 기록이 유지됩니다.

현재 버전은 계정이나 서버 데이터베이스를 사용하지 않으므로 다음 사항에 유의해 주세요.

- 다른 기기나 브라우저와 기록이 동기화되지 않습니다.
- 브라우저 사이트 데이터를 삭제하면 저장한 기록도 함께 삭제됩니다.
- 처음 방문하면 서비스 사용 예시를 위한 샘플 기록이 표시됩니다.

## 시작하기

### 요구 사항

- Node.js 22.13.0 이상
- npm

### 설치 및 실행

```bash
npm install
npm run dev
```

개발 서버가 시작되면 터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

### 배포용 빌드

```bash
npm run build
npm run start
```

### 코드 검사

```bash
npm run lint
```

## 기록 항목

각 커피 기록은 다음 정보를 포함합니다.

| 항목 | 설명 |
| --- | --- |
| 커피 이름 | 원두나 메뉴의 이름 |
| 로스터리 | 커피를 로스팅하거나 판매한 곳 |
| 원산지 | 국가와 생산 지역 |
| 마신 날짜 | 커피를 경험한 날짜 |
| 추출 방식 | 선택한 브루잉 방식 |
| 평점 | 5점 만점의 개인 평가 |
| 테이스팅 노트 | 향, 맛, 온도와 인상에 관한 메모 |
| 향미 태그 | 검색과 분류에 활용할 키워드 |
